- `scripts/symbol_usage.py` records which fleet repos use each tollbooth-dpyc and tollbooth-web symbol, and marks a symbol `unused` when no fleet repo imports it and the SDK never reads it. It writes only the symbols whose usage changed. The weekly Intention Forward Map sweep runs it after the indexer, and only when the whole fleet checked out. Deciding that a symbol is obsolete stays a human call (`retire_symbol`).
